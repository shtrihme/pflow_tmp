# Документация проекта

Справочники по работе с этой моделью — для тебя и для агента. Лежат прямо в проекте.

## Язык модели (DSL)
- [dsl-guide.md](dsl-guide.md) — карта сущностей обоих DSL (`pflow` — стратегия, `svcflow` — операционка) через продуктовые вопросы, cross-layer связи.
- [dsl-reference.md](dsl-reference.md) — справочник по каждой сущности: роль, как назвать, что писать, антипаттерны. Автоген — руками не править.

## Как работать
- [use-cases.md](use-cases.md) — кейсы PM-команды: агент делает 80%+ изменений, что остаётся человеку.
- [aspects.md](aspects.md) — дерево аспектов как рабочая поверхность продакта.
- [cabinet-init.md](cabinet-init.md) — как заполнить модель нового продукта с нуля (кабинетный ресёрч).
- [productops-tasks.md](productops-tasks.md) — задачи продакта по фазам Discovery → Strategy → Delivery → Growth → Ops.

## Возможности инструмента
- [ide.md](ide.md) — VS Code-расширение: деревья, диаграмма, инлеи, hover, команды.
- [mcp.md](mcp.md) — инструменты агента (Claude Code и совместимые) + подключение.
- [cli.md](cli.md) — контекст и инструменты из командной строки, CI-гейт корректности.
- [web.md](web.md) — web-витрина: просмотр модели из GitHub, шеринг, сравнение версий, печать.

> Роль агента и правило «MCP first» — в `AGENTS.md` / `CLAUDE.md` в корне проекта. Тур по стартеру — в `README.md`.
