# IDE: возможности расширения

Что даёт VS Code-расширение ProductFlow при работе с `.pflow`/`.sflow`. Это поверхность для **человека** — навигация, осмотр, ручные правки; массовые изменения делает агент ([mcp.md](mcp.md)).

## Дерево проекта (Activity Bar → ProductFlow)

Два дерева:

- **🗂 Аспекты** — narrative-первая карта проекта: project-обзор + страница на каждый Канвас. Узлы помечены статусом summary (✨ свежая / ⚠ устарела / ? нет) и health-флагами. Главная рабочая поверхность продакта — подробно в [aspects.md](aspects.md).
- **📚 Реестр** — типологический индекс всех сущностей обоих DSL + секция **🩺 Здоровье** наверху: чекеры модели (сироты, broken-refs, unfounded, юнит-экономика, имена…) раскрываются до конкретных находок, клик ведёт к декларации. Живой поиск — иконка 🔍 (фильтр по дереву).

Бейдж на дереве показывает число сущностей или проблем; status bar внизу — сводку состояния модели.

## Подсказки в коде

- **Inlay-хинты** — рядом с именем сущности: что она такое (forward-ссылки, статус, экономика), а после `}` — кто на неё ссылается (`↗`), сигналы (✅/❌), `⚠️ не используется` у сирот. Ховер по любому бейджу — карточка с именами за счётчиками.
- **Hover** — документация по каждой сущности и ключевому слову + список обратных ссылок.
- **Outline / breadcrumbs** — иерархия сущностей с эмодзи; для сущности-по-ссылке показывается имя цели.
- **Code Lens** `🎯 Показать в дереве` — над именем top-level сущности.
- **Проблемы (Problems panel)** — ошибки/предупреждения валидаторов корректности + attention-находки здоровья. Полная карта проверок — в дереве Здоровья.
- **Автодополнение, переименование по всему воркспейсу, форматирование** — стандартно.

## Диаграмма связей

Команда **ProductFlow: Show Canvas Diagram** (иконка в тулбаре при открытом `.pflow`) открывает граф связей по всему воркспейсу.

**Фокус** (выпадающий список в тулбаре):
- **Весь воркспейс** — все продукты, сегменты, фичи и связи.
- **Канвас:** *X* — выбранный Канвас со всем содержимым + сегменты, на которые он ссылается.
- **Сегмент:** *X* — сегмент и все продукты, ссылающиеся на него (изолированный узел = полезный сигнал).
- **Работа:** *X* — Работа и все адресующие её Канвасы.

**Узлы** раскрашены по типу (🔵 Сегмент · 🟢 VPC/Предложение/Ресурс · 💼 Работа · 🟠 Переключение/Альтернатива · 🟣 Юнит/Активность · 🤝 Партнёр · 🧩 Компонент · ⬛ Канвас-группа). **Стрелки** с лейблами связей (`сегмент`, `адресует`, `решает`/`решает частично`); Связки — пунктир, Петли — жирные стрелки с триггером. **Бейджи сигналов** под узлами (`✅N` подтверждают · `❌N` опровергают · `➡️N` связаны) — сразу видно, где есть данные, а где догадки.

**Навигация:** клик → к определению; правый клик → «Скопировать контекст этого узла»; колесо — зум; перетаскивание — панорама; `+`/`−`/`⊙` — зум/сброс.

## Граф (панель «Связи»)

Команда **ProductFlow: Открыть граф** — force-directed граф всех сущностей и ссылок (degree-счётчики, клик → к источнику).

## Контекст для чата с LLM

Срез канваса (сущность с соседями / продукт / весь воркспейс) копируется в буфер как структурированный markdown — оглавление, разделы по сущностям, явные cross-refs («Предложение → Работа», «Канвас → VPC»). Готово для вставки в любой LLM-чат.

**Три точки запуска:**
| Откуда | Что копируется |
|---|---|
| Кнопка **📋 Контекст** в тулбаре диаграммы | То, что видно на канвасе сейчас (с учётом фокуса) |
| Правый клик на узле → **Скопировать контекст узла** | Сущность + всё, на что она ссылается и что ссылается на неё (один уровень) |
| Палитра → **Скопировать контекст для чата** | Курсор на сущности → «сущность + соседи»; один Канвас → «канвас»; иначе → весь воркспейс |

После копирования — уведомление с числом сущностей. То же доступно из CLI — [cli.md](cli.md).
