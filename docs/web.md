# Web-витрина: просмотр модели из GitHub

Помимо редактора есть **web-просмотр pflow-проекта прямо из GitHub** — отдельный read-only продукт для шеринга модели со стейкхолдерами без установки VS Code.

## Что умеет

- **Открыть любой репозиторий** по ссылке `/r/:owner/:repo` — витрина клонирует репо, парсит `.pflow`/`.sflow` и рисует narrative-первую страницу проекта (Юнит-шапка → фрейм → Канвасы → бэкстейдж). Приватные репо — через вход по GitHub.
- **Выбор версии** — ветка, тег или открытый PR (селектор вверху); кнопка sync подтягивает свежий коммит.
- **Здоровье** — бейдж ⚠ открывает панель «Проблемы»: health-находки по аспектам с подсказками «как починить» + секция «Корректность модели» (ошибки валидаторов). Клик по находке скроллит к месту в модели.
- **Реестр сущностей** — боковая панель с оглавлением и индексом; клик скроллит + подсвечивает узел.
- **Сравнение версий** `/r/:owner/:repo/compare` — diff двух коммитов по сущностям и аспектам (что добавилось/изменилось), с опциональным LLM-резюме изменений.
- **Печать / PDF** — диалог печати настраивает разделы/канвасы/глубину и открывает чистую печатную страницу (`window.print()`).
- **Моно-репо** — если в репозитории несколько pflow-проектов (по маркеру `.pflow/`), витрина даёт выбрать нужный.

## Связь с моделью

Витрина показывает тот же `Snapshot`, что и расширение (нарратив + здоровье + реестр + канвасы), но **только для чтения** — это витрина, а не редактор. Изменения вносятся в `.pflow` через редактор/агента и попадают в витрину после `git push` + sync.

## CI-интеграция

При открытии PR можно автоматически прогревать витрину и постить ссылку-превью комментарием — через workflow'ы, которые раскатываются вместе с проектом (`.github/workflows/pflow-viewer.yml`, `pflow-diff.yml`). Гейт корректности — [cli.md](cli.md).

> Запуск/деплой самой витрины (это уже про инфраструктуру тула, не про проект) — в репозитории ProductFlow, `docs/claude/web-internals.md`.
