# Voice — голос проекта

Опциональный файл: задаёт общий тон и формат narrative-сводок, которые
агент пишет через MCP-tool `pflow_aspect_v2_save`. Применяется ПОВЕРХ
per-aspect `prompt`'а:

- `prompt` (в каждом аспекте) — **семантика слота** (что должно быть,
  структура, длина) **+ общий гайд по разметке** (`**bold**` на
  ключевых сущностях/метриках, `\n\n` между смысловыми блоками,
  эмодзи-маркеры по семантике — ✅/🟡/🔒/⚠️/📈/⏱️/🔁/💼/🤝 и т.п.).
  Разметка идёт автоматически — voice.md нужен, только если хочешь её
  ослабить (например, запретить эмодзи) или ужесточить (свои маркеры);
- `voice.md` (этот файл) — **голос проекта** (тон, аудитория, запреты).

Чтобы включить — раскомментируй секции ниже и заполни своими словами.
Если файла нет или он пустой — агент будет писать в нейтральном стиле
с применением общей разметки и мимикрией под уже написанные соседние
блоки.
